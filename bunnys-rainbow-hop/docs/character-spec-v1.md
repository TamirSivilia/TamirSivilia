# Bunny's Rainbow Hop — character reference v1

Created with the built-in image generation tool. Reference: bunny-frog-reference-v1.png. This is a first design reference, not a completed animation or a user-approved final design.

## Design
Bunny: fluffy ivory-white rabbit, expressive long pink-lined ears, warm dark eyes, blue overalls with two golden buttons, bare rounded paws. Frog: small rounded green frog, pale belly, expressive eyes, no clothing. Keep four limbs and stable clothing/anatomy. The sheet is a visual style reference rather than a calibrated scale drawing; in scenes Frog should be approximately one third Bunny's standing height including ears.
