# SOLO — רותם כהנים

אתר, קורס דיגיטלי ואזור מתאמנות. Node.js (ללא Express) + SQLite מובנה (`node:sqlite`), בלי תלות בבילד/פריימוורק פרונט.

## מה עובד עכשיו (נבדק אוטומטית ב־`tests.mjs`, 20/20 עוברים)

- דף נחיתה בעברית, RTL, מיתוג SOLO — היירו, מי אני, הקורס, למי מתאים/לא מתאים, ה"סטייטמנט", CTA לוואטסאפ. כל הטקסטים ניתנים לעריכה מהניהול (`/admin`) בלי לגעת בקוד.
- כניסת מתאמנות בטלפון + קוד חד־פעמי (`/learn`): רשימת שיעורים שפורסמו בלבד (טיוטות מוסתרות), סימון "הושלם", מאגר תרגילים לפי קבוצת שריר, טבלת מעקב אישית (הוספה/מחיקה) עם ייצוא ל־CSV.
- ניהול (`/admin`): הוספת מתאמנת עם מניעת מספר כפול, השהיה/חידוש גישה (השהיה מנתקת session פעיל מיידית), הוספה/עריכה/מחיקה של שיעורים (טיוטה/פרסום, בדיקת תקינות קישור YouTube), עריכת כל תוכן דף הנחיתה.
- כל הנתונים נשמרים ב־SQLite (`data/solo.db`), לא בזיכרון — שורדים הפעלה מחדש של השרת.

## מה עדיין לא מחובר

- **SMS אמיתי**: הקוד כולל אינטגרציה מלאה ל־Twilio Verify (`lib/sms.mjs`), אבל היא לא פעילה כי אין חשבון/מפתחות. בלי הגדרה, השרת מסרב לעבוד עם `NODE_ENV=production` — וב־`DEV_PREVIEW=true` (לבדיקה מקומית בלבד) הקוד מודפס לקונסול ומוחזר גם ב־API, כדי שאפשר יהיה לבדוק את כל הזרימה בלי SMS.
- **אתר לא פורסם לאינטרנט** — רץ מקומית בלבד עד כה.
- **אין מחיר או סליקה** — ההצטרפות מפנה לוואטסאפ, כמו שהוגדר.
- **תוכן אמיתי חסר**: אין סרטונים אמיתיים מחוברים, אין צילום של רותם (יש "חותם" גרפי זמני מכוון, לא תמונה מזויפת ולא מלבן ריק), הביוגרפיה בדף היא טיוטה לאישור.
- **מאגר תרגילים**: כרגע רשימת זרעים (seed) קבועה בקוד (`lib/db.mjs`), לא ניתנת לעריכה מהממשק — כפי שהוגדר בהיקף המקורי.

## הרצה מקומית

```bash
npm run configure-admin   # מגדיר שם משתמש/סיסמה למנהלת (אינטראקטיבי)
npm run dev                # מפעיל עם DEV_PREVIEW=true על פורט 4317
```

- דף נחיתה: http://127.0.0.1:4317/
- ניהול: http://127.0.0.1:4317/admin
- אזור מתאמנות: http://127.0.0.1:4317/learn

ב־`DEV_PREVIEW=true` קודי האימות (SMS) מוצגים ישירות במסך ובתגובת ה־API, כדי לאפשר בדיקה מלאה בלי ספק SMS. **מצב זה חייב להיות כבוי ב־production** — השרת מסרב לעלות אם `DEV_PREVIEW=true` וגם `NODE_ENV=production`.

## בדיקות

```bash
npm test
```

מריץ שרת אמיתי על DB זמני ובודק: חסימת גישה ללא התחברות, דחיית סיסמה שגויה, מניעת מספר טלפון כפול, זרימת כניסה של מתאמנת, הסתרת טיוטות, סימון שיעור כהושלם, שמירת טבלת מעקב וייצוא CSV, ניתוק גישה מיידי בהשהיה, ועריכת תוכן דף הנחיתה.

## לפני פריסה לפרודקשן

1. להריץ `npm run configure-admin` בסביבת הפרודקשן (לא לשמור סיסמה בקוד).
2. להגדיר ספק SMS אמיתי (`TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_VERIFY_SERVICE_SID` ב־`.env`) — עד אז אין דרך אמיתית להתחבר.
3. לוודא `NODE_ENV=production` ו־`DEV_PREVIEW` לא מוגדר/`false`.
4. לבחור אירוח שמריץ שרת Node מתמשך (לא סטטי בלבד) עם דיסק מתמשך ל־SQLite וגיבויים סדירים — או להעביר ל־DB מנוהל אם רוצים לוותר על הקובץ המקומי.
5. לבדוק ידנית: כניסת מנהלת אמיתית, כניסת מתאמנת אמיתית עם SMS אמיתי, צפייה בשיעור, שמירת התקדמות, השהיית מתאמנת.

## מבנה הפרויקט

```

lib/db.mjs            חיבור SQLite + סכימה + נתוני זרע
lib/auth.mjs           סשנים, האשינג סיסמאות, קודי אימות
lib/sms.mjs             שליחת קוד (Twilio Verify / מצב בדיקה מקומי)
configure-admin.mjs     הגדרת שם משתמש/סיסמה למנהלת (CLI אינטראקטיבי)
public/index.html       דף נחיתה
public/learn.html+js    אזור מתאמנות
public/admin.html+js    ניהול
public/style.css        עיצוב דף הנחיתה (מיתוג SOLO)
public/app-shared.css   עיצוב משותף לאזור מתאמנות + ניהול
tests.mjs               בדיקות אינטגרציה (node --test)
```
